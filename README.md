# Lectura Nave 5

App del operario para registrar la lectura del medidor de energía de la Nave #5
(formato MTO-R007-TXN2). Se instala en el teléfono desde GitHub Pages y envía cada
lectura al servidor de Google Apps Script, que arma el Reporte Diario de Consumo Energético.

Configuración: abrir la app una vez con `?api=` seguido de la URL `/exec` del Apps Script.
